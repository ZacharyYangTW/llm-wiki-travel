# Rebuild Taiwan China Japan Skill

重建台灣、中國、日本的 Wiki 目錄結構，使用完整地理編碼。

## 用途

從 KML 中提取中日台的所有 POI，根據地理位置進行編碼，並按照二級結構重建目錄：

- **台灣**: `wiki/台灣/{縣市}/{鄉鎮市區}/`
- **中國**: `wiki/中國/{省份}/{城市}/`
- **日本**: `wiki/日本/{都道府縣}/{市區町村}/`

## 使用方式

```
/rebuildChinaJapan
```

## 功能

### 地理編碼方式

使用座標距離算法，根據 POI 坐標找到最近的一級行政區（縣市/省份/都道府縣）：

1. **台灣**: 22 個縣市中心座標
2. **中國**: 34 個省份/直轄市中心座標
3. **日本**: 47 個都道府縣中心座標

### 進度報告

每 10 秒報告進度，包括：
- 已掃描 POI 數
- 各國家 POI 分類統計
- 已建立檔案數
- 預計剩餘時間

### 輸出

每個 POI 創建一個 Markdown 檔案：

```markdown
---
name: POI名稱
type: place
coordinates: [lng, lat]
created_at: 2026-05-12T12:34:56.789012
---

# POI名稱

**座標:** lat, lng
**國家:** 台灣
**區域:** 台北市 / 中正區

## 基本資訊

## 備註
```

## 技術細節

### 座標範圍判斷

- **台灣**: 120° ~ 122°E, 22° ~ 26°N
- **中國**: 73° ~ 135°E, 18° ~ 54°N（排除台灣）
- **日本**: 130° ~ 145°E, 30° ~ 46°N

### 計數結果範例

```
⏱️ [  10.0s] 進度:   125/8383 (  1.5%) | 台  10 中  85 日  15 其他 15 | 已建  110 | 預計剩餘: 661s
```

## 注意事項

1. 所有檔案名都會移除換行符和特殊字符
2. 重複的檔案不會被覆蓋
3. 無法分類的 POI 會被歸入"未分類"和"其他"
4. 所有目錄和檔案名都使用繁體中文
