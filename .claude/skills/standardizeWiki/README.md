# standardizeWiki Skill

## 目的
自動檢測和修正 Wiki 中的命名標準化問題：
1. **簡繁體混用**: 統一為繁體字
2. **一字之差重複**: 統一為有"市"/"縣"等後綴的版本
3. **日本繁體字**: 統一為日文漢字（県、都、道、府）
4. **相似目錄**: 統一為更完整的版本（如 大邱 → 大邱廣域市）

## 快速開始
```bash
# 完整掃描和修正（自動化）
python standardize_all.py

# 僅掃描，不修正
python standardize_wiki.py
```

## 掃描功能

### standardize_wiki.py
僅執行掃描，報告發現的問題：
- 簡繁體混用的目錄
- 一字之差重複的目錄
- 日本繁體字目錄
- 相似目錄

**輸出範例**:
```
⚠️  發現 2 個簡體字目錄
  中國/甘肅省/兰州市 → 蘭州市
  中國/廣東省/云浮 → 雲浮

⚠️  發現 5 個日本繁體字
  日本/神奈川県/神奈川縣 → 神奈川県
  ...
```

## 自動修正功能

### standardize_all.py
自動掃描和修正所有發現的問題：

**執行步驟**:
1. 掃描整個 Wiki
2. 識別所有標準化問題
3. 顯示詳細清單
4. 自動執行修正
5. 驗證完成

**修正類型**:
- ✅ 簡體字目錄改名（如 兰州市 → 蘭州市）
- ✅ 一字之差目錄合併（如 廣州 → 廣州市）
- ✅ 相似目錄合併（如 大邱 + 大邱廣域市 → 大邱廣域市）
- ✅ 日本繁體字改正（如 福岡縣 → 福岡県）

## 處理的命名問題

### 1. 簡繁體混用
**檢測**: 目錄名包含已知的簡體字

**修正規則**:
```
兰州市 → 蘭州市
云浮 → 雲浮
苏州 → 蘇州
```

### 2. 一字之差重複
**檢測**: 同一級別中，一個目錄是另一個目錄加上"市""縣""區"等後綴

**修正規則**:
```
廣州 + 廣州市 → 廣州市（保留有後綴的版本）
蘭州 + 蘭州市 → 蘭州市
拉薩 + 拉薩市 → 拉薩市
```

### 3. 日本繁體字
**檢測**: 日本都道府縣下有繁體中文版本的目錄

**修正規則**:
```
神奈川縣 → 神奈川県（改為日文漢字）
福岡縣 → 福岡県
長崎縣 → 長崎県
```

### 4. 相似目錄
**檢測**: 兩個目錄名高度相似，一個是另一個的簡短版本

**修正規則**:
```
大邱 + 大邱廣域市 → 大邱廣域市（合併到完整版本）
首爾 + 首爾特別市 → 首爾特別市
仁川 + 仁川廣域市 → 仁川廣域市
```

## 注意事項

### 修正是破壞性操作
- 執行前建議備份 Wiki 目錄
- 修正會移動和刪除目錄，無法撤銷

### 文件衝突處理
- 如果目標目錄已存在，會自動合併檔案
- 同名檔案會被覆蓋（來自目標版本的檔案優先）

### 某些情況需要人工判斷
- 新增的相似目錄（可在 SIMILAR_DIRS_MAP 中配置）
- 特殊地名的繁簡轉換（需驗證準確性）

## 更新命名規則

如需更新簡體字、日本繁體字或相似目錄的映射表，編輯 `standardize_all.py` 中的常數：

```python
SIMPLIFIED_CITIES = { ... }          # 簡體字映射
JAPAN_TRADITIONAL_MAP = { ... }      # 日本繁體字映射
SIMILAR_DIRS_MAP = { ... }           # 相似目錄映射
```
