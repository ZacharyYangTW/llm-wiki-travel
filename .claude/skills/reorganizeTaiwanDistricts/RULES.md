# 🔒 台灣 POI 重新整理 - 硬性規則（永久不動）

## 目錄結構規則
```
wiki/台灣/{縣市}/{鄉鎮市區}/*.md
```
- **三層結構**：必須有縣市 → 鄉鎮市區兩層
- **不准有"其他"資料夾**：所有檔案必須分類到具體的鄉鎮市區

---

## Case 定義

### Case 1: 驗證正確位置的檔案
**掃描位置**：`wiki/台灣/{縣市}/{鄉鎮市區}/*.md`
**功能**：
- 檢查座標是否真的在指定的鄉鎮市區邊界內
- 報告位置正確或錯誤
**輸出**：位置正確數 / 位置錯誤數 / 無法定位數

### Case 2: 清空"其他"目錄
**掃描位置**：`wiki/台灣/{縣市}/其他/*.md`
**功能**：
- 根據座標找到正確的鄉鎮市區
- 移動檔案到正確位置
- **重要規則**：目標檔案已存在 → 刪除源檔案（只保留一份，不加序號 _1 _2 _3）
- 清理所有空的"其他"資料夾
**輸出**：已移動數 / 移動失敗數 / 無法定位數

### Case 3: 處理缺少鄉鎮市區層級的檔案
**掃描位置**：`wiki/台灣/{縣市}/*.md`（直接在縣市下）
**功能**：
- 根據座標找到正確的鄉鎮市區
- 移動檔案到正確位置
**輸出**：已移動數 / 移動失敗數 / 無法定位數

## 技術細節（不准改）

### 座標系統
- WGS84 (GPS 座標)
- 格式：`coordinates: [lng, lat]`

### 邊界資料
- 檔案：`twtown2010.json`
- 格式：GeoJSON MultiPolygon
- 台灣 374 個鄉鎮市區邊界

### 座標驗證方法
- 射線投射演算法 (Ray Casting)
- 判斷點是否在多邊形內

### 進度報告
- **頻率**：每 10 秒報告一次
- **格式**：
  ```
  ⏱️ [時間] 進度: 已處理/總數 (百分比) | 統計數據 | 預計剩餘時間
  ```

### 檔案移動規則
1. 建立目標目錄 `wiki/台灣/{縣市}/{鄉鎮市區}/`
2. 檢查目標檔案是否存在
3. 如果存在 → **刪除源檔案**（保留目標）
4. 如果不存在 → 移動源檔案到目標位置
