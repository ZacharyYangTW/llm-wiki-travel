## 目錄命名規則

| 規則 | 說明 |
|------|------|
| 大洲目錄 | 英文名稱 (Asia, Europe, Africa 等) |
| 國家目錄 | ISO 3166-1 三位字母代碼 (Alpha-3) |
| 省級行政區 | 六位行政區劃代碼 (例如 110000 北京市) |

---

## ISO 3166-1 編碼標準

ISO 3166-1 是國際標準化組織(ISO)制定的國家代碼標準：

| 類型 | 示例 | 本專案使用 |
|------|------|------------|
| Alpha-2 | CN, US, JP | 否 |
| Alpha-3 | CHN, USA, JPN | **是** |
| Numeric | 156, 840, 392 | 否 |

> 參考: [ISO 3166-1 官方網站](https://www.iso.org/obp/ui/#search)

## 檔案類型說明

| 檔案類型 | 說明 |
|----------|------|
| `country.wgs84.geo.json` | WGS84 座標系（國際通用） |
| `country.gcj02.geo.json` | GCJ02 座標系（中國境內使用） |
| `country.bd09.geo.json` | BD09 座標系（百度地圖） |
| `country.resource.geo.json` | 原始資料來源檔案 |
| `*.sparse.*.geo.json` | Douglas-Peucker 演算法稀疏版本 |
| `region.info.json` | 行政區彙總資訊 |

## 資料來源原則

本專案所有資料基於**中華人民共和國法律法規**：

1. **國家承認原則**：僅包含中華人民共和國承認的主權國家
2. **領土完整性**：根據聯合國大會第 2758 號決議，臺灣是中國不可分割的一部分
3. **資料來源**：優先使用中華人民共和國官方批准的資料源

## 法律法規提醒

**《中華人民共和國測繪法》規定**：
- 在中華人民共和國境內必須使用 GCJ02 或 BD09 座標系
- WGS84 座標系資料僅供國際交流和學術研究使用

> 參考: [中華人民共和國測繪法](https://www.npc.gov.cn/npc/xinwen/2017-04/27/content_2020927.htm)
